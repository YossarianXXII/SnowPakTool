- **SnowDeskTool** is a Windows app for editing and repacking SnowRunner game data. My main focus was on randomization of trucks/upgrades and doing it with few clicks and with reasonable difficulty options.
  - **Start** — Unpack an initial PAK, review staged changes, apply them to your workspace, and pack a new PAK.
  - **Editors** — Edit truck properties, engines, winches, addons, trailers, cargo mass, rank XP, and tire ice behavior.
  - **Planning** — Set DLC ownership, truck groups and tiers, region difficulty, and progression order.
  - **Randomizer** — Shuffle obtainable trucks, mission trucks, and map upgrades. Preview or reset placements before applying changes.
  - **Shared presets** — Save or load a `.snowpreset` to share a setup. Applying it requires matching original game files.
- **Game files**
  - Keep backups of your original PAKs.
  - Stage edits, then select **Start → Apply pending changes** to write them to your workspace.
  - Pack a new initial PAK and install it and any edited map files manually.
- **Build from source** — Use Windows and the [.NET SDK selected by the project](global.json). Run these commands from the repository root.
  - Build — `pwsh ./tools/Build.ps1`
  - Test — `pwsh ./tools/Test.ps1`
  - Publish — `pwsh ./tools/Publish.ps1`
  - Open `artifacts/publish/SnowPakTool.Desktop/SnowPakTool.Desktop.exe` after publishing.
- **SnowPakTool CLI** — Pack PAKs, extract or rebuild cache blocks, and create asset-loading and sound lists. The desktop app uses its archive code.
